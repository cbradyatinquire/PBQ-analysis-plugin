# Privacy Policy — PBQ Analysis Add-on

**Last updated: July 14, 2026**

## Overview

PBQ Analysis is a Google Sheets™ add-on for educators that visualizes student response patterns from Google Forms™ checkbox questions. This policy describes how the add-on handles data.

## Data accessed

To function, PBQ Analysis requests access to:

- **Google Sheets™** — to read response data in the active spreadsheet and write chart data to it
- **Google Forms™** — to read question options and structure from forms linked by the user

## Data storage and sharing

- PBQ Analysis does **not** transmit any data outside of your Google account
- PBQ Analysis does **not** store any spreadsheet or form data on external servers
- All processing occurs entirely within Google's infrastructure (Apps Script), under your own Google account
- Form URLs entered by the user are stored in Google's PropertiesService, which is scoped to your installation of the add-on and is not accessible to anyone else

## Data protection

All data accessed by PBQ Analysis remains within Google's infrastructure at all times. The add-on operates exclusively as a Google Apps Script application, meaning:

- No data is transmitted to any external server or third-party service
- All computation occurs within Google's secure Apps Script runtime environment
- Access to your spreadsheet and form data is governed by Google's own security and privacy controls
- The add-on only accesses the active spreadsheet and forms explicitly linked by the user

## Data retention and deletion

PBQ Analysis does not retain or store user data beyond what Google's own infrastructure maintains:

- The only data stored by the add-on is the form URL(s) you provide, held in Google's PropertiesService scoped to your installation
- This stored data can be cleared at any time by uninstalling the add-on
- No spreadsheet content, form responses, or student data is retained anywhere by the add-on
- Upon uninstalling the add-on, all PropertiesService data associated with it is deleted

To delete all data associated with PBQ Analysis, uninstall the add-on via the Google Workspace Marketplace and revoke its permissions at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

## Student data

This add-on is intended for use by educators to analyze aggregated student response patterns. No individual student data is transmitted, stored externally, or shared with any third party.

## Third parties

PBQ Analysis does not integrate with any third-party services, analytics platforms, or advertising networks.

## Changes to this policy

If this policy is updated, the "Last updated" date above will be revised. Continued use of the add-on after changes constitutes acceptance of the updated policy.
