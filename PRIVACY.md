# Privacy Policy — PBQ Analysis Add-on

**Last updated: June 16, 2026**

## Overview

PBQ Analysis is a Google Sheets add-on for educators that visualizes student response patterns from Google Forms checkbox questions. This policy describes how the add-on handles data.

## Data accessed

To function, PBQ Analysis requests access to:

- **Google Sheets** — to read response data in the active spreadsheet and write chart data to it
- **Google Forms** — to read question options and structure from forms linked by the user

## Data storage and sharing

- PBQ Analysis does **not** transmit any data outside of your Google account
- PBQ Analysis does **not** store any spreadsheet or form data on external servers
- All processing occurs entirely within Google's infrastructure (Apps Script), under your own Google account
- Form URLs entered by the user are stored in Google's PropertiesService, which is scoped to your installation of the add-on and is not accessible to anyone else

## Student data

This add-on is intended for use by educators to analyze aggregated student response patterns. No individual student data is transmitted, stored externally, or shared with any third party.

## Third parties

PBQ Analysis does not integrate with any third-party services, analytics platforms, or advertising networks.

## Changes to this policy

If this policy is updated, the "Last updated" date above will be revised. Continued use of the add-on after changes constitutes acceptance of the updated policy.
